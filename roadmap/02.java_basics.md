# 02. Java Cơ bản

> **Mục tiêu:** Nắm vững cú pháp và các khái niệm nền tảng của Java.

---

## 1. Cú pháp cơ bản

> **🔍 WHAT:** Cú pháp cơ bản Java là tập hợp các quy tắc viết code: khai báo biến, kiểu dữ liệu, cách viết câu lệnh đầu tiên.
>
> **💡 WHY:** Đây là nền tảng bắt buộc – không hiểu cú pháp thì không thể viết được bất kỳ chương trình Java nào. Mọi framework như Spring Boot đều viết trên nền này.
>
> **⚙️ HOW:** Java là ngôn ngữ strongly-typed (phải khai báo kiểu dữ liệu rõ ràng), mọi code phải nằm trong class, entry point là method `public static void main(String[] args)`.
>
> **📍 WHEN/WHERE:** Áp dụng từ dòng code đầu tiên, trong mọi file `.java` của dự án – từ entity đến controller đến test.

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

> **📝 Giải thích chi tiết code:**
> * `public class HelloWorld`: Khai báo một lớp (class) có tên là `HelloWorld` và có phạm vi truy cập là công khai (`public`). Trong Java, tên class public phải trùng khớp hoàn toàn với tên file (ở đây là `HelloWorld.java`).
> * `public static void main(String[] args)`: Đây là phương thức khởi chạy (entry point) của mọi ứng dụng Java độc lập. Máy ảo Java (JVM) sẽ luôn tìm và thực thi phương thức này trước tiên:
>   * `public`: Phương thức có thể được gọi từ bất kỳ đâu (ở đây là JVM gọi).
>   * `static`: Phương thức tĩnh, có thể chạy trực tiếp mà JVM không cần khởi tạo một đối tượng (object) từ class HelloWorld.
>   * `void`: Kiểu trả về là rỗng, nghĩa là phương thức này không trả về giá trị nào cho môi trường gọi sau khi kết thúc.
>   * `String[] args`: Tham số đầu vào là một mảng các chuỗi ký tự (String), cho phép truyền dữ liệu từ dòng lệnh vào chương trình khi khởi chạy.
> * `System.out.println("...")`: Lệnh in chuỗi ký tự ra màn hình console của hệ thống và tự động xuống dòng sau khi in.

### 1.2 Kiểu dữ liệu nguyên thủy

| Kiểu | Kích thước | Phạm vi | Ví dụ |
|------|-----------|---------|-------|
| `byte` | 1 byte | -128 đến 127 | `byte b = 100;` |
| `short` | 2 bytes | -32768 đến 32767 | `short s = 1000;` |
| `int` | 4 bytes | ~-2.1 tỷ đến 2.1 tỷ | `int i = 42;` |
| `long` | 8 bytes | rất lớn | `long l = 9999999999L;` |
| `float` | 4 bytes | thập phân 6-7 chữ số | `float f = 3.14f;` |
| `double` | 8 bytes | thập phân 15 chữ số | `double d = 3.14159;` |
| `char` | 2 bytes | ký tự Unicode | `char c = 'A';` |
| `boolean` | 1 bit | true/false | `boolean ok = true;` |

### 1.3 Kiểu tham chiếu

```java
String name = "Java";           // String (không phải primitive)
int[] numbers = {1, 2, 3, 4};  // Array
Integer boxed = 42;             // Wrapper class (autoboxing)
```

> **📝 Giải thích chi tiết code:**
> * `String name = "Java"`: `String` là một class (kiểu tham chiếu), đại diện cho một đối tượng chứa chuỗi ký tự. Biến `name` không chứa trực tiếp chữ "Java" mà chứa địa chỉ vùng nhớ trỏ tới đối tượng String "Java" trên Heap memory.
> * `int[] numbers`: Khai báo một biến mảng kiểu `int`. Mảng trong Java cũng là đối tượng (kiểu tham chiếu).
> * `Integer boxed = 42;`: `Integer` là một **Wrapper class** (lớp bao bọc) cho kiểu dữ liệu nguyên thủy `int`. Cơ chế **Autoboxing** của Java sẽ tự động chuyển đổi số nguyên nguyên thủy `42` thành một đối tượng `Integer` tương ứng mà không cần viết `Integer.valueOf(42)`.

## 2. Toán tử

> **🔍 WHAT:** Toán tử là các ký hiệu/từ khóa thực hiện phép tính trên biến và giá trị: số học, so sánh, logic, gán.
>
> **💡 WHY:** Toán tử là công cụ để xây dựng mọi logic nghiệp vụ – tính toán giá tiền, so sánh điều kiện, kết hợp nhiều điều kiện lại với nhau.
>
> **⚙️ HOW:** Java ưu tiên các toán tử theo thứ tự precedence (ví dụ: `*` trước `+`). Toán tử `==` so sánh giá trị với primitive nhưng so sánh địa chỉ với object – dùng `.equals()` cho object.
>
> **📍 WHEN/WHERE:** Dùng trong mọi biểu thức logic, điều kiện if, tính toán trong service layer và business logic.

```java
// Số học
int a = 10, b = 3;
System.out.println(a + b);   // 13
System.out.println(a - b);   // 7
System.out.println(a * b);   // 30
System.out.println(a / b);   // 3 (chia nguyên)
System.out.println(a % b);   // 1 (chia lấy dư)

// So sánh
System.out.println(a > b);   // true
System.out.println(a == b);  // false

// Logic
System.out.println(true && false); // false (AND)
System.out.println(true || false); // true  (OR)
System.out.println(!true);         // false (NOT)

// Gán kết hợp
a += 5;  // a = a + 5
a++;     // a = a + 1
```

> **📝 Giải thích chi tiết code:**
> * `a / b`: Vì cả `a` và `b` đều là kiểu số nguyên `int`, phép chia `/` sẽ là phép chia lấy phần nguyên (bỏ qua phần thập phân). Kết quả của `10 / 3` là `3`.
> * `a % b`: Toán tử Modulo `%` lấy số dư của phép chia. `10 % 3` dư `1`.
> * `&&` và `||`: Các toán tử logic ngắn mạch (short-circuit logic). `&&` sẽ dừng và trả về `false` ngay lập tức nếu vế trái là `false` mà không cần tính vế phải. Tương tự, `||` sẽ trả về `true` ngay nếu vế trái là `true`.
> * `a += 5` và `a++`: Các toán tử gán rút gọn và toán tử tăng. `a++` tương đương với `a = a + 1`.

## 3. Cấu trúc điều khiển

> **🔍 WHAT:** Cấu trúc điều khiển là các lệnh quyết định luồng thực thi của chương trình: rẽ nhánh (if/switch) và lặp (for/while).
>
> **💡 WHY:** Không có điều khiển luồng thì code chỉ chạy từ trên xuống dưới – không thể xử lý nghiệp vụ phức tạp như "nếu user là admin thì cho phép xóa".
>
> **⚙️ HOW:** `if-else` và `switch` để rẽ nhánh theo điều kiện; `for`, `while`, `do-while` để lặp lại khối code; `break` thoát vòng lặp, `continue` bỏ qua iteration hiện tại.
>
> **📍 WHEN/WHERE:** Dùng khắp nơi trong business logic – validation điều kiện, xử lý danh sách, thực hiện lặp trên tập dữ liệu.

```java
// if-else
int score = 75;
if (score >= 90) {
    System.out.println("Xuất sắc");
} else if (score >= 70) {
    System.out.println("Khá");
} else if (score >= 50) {
    System.out.println("Trung bình");
} else {
    System.out.println("Yếu");
}

// switch (Java 14+ pattern)
String day = "MON";
switch (day) {
    case "MON", "TUE", "WED", "THU", "FRI" -> System.out.println("Ngày làm việc");
    case "SAT", "SUN" -> System.out.println("Cuối tuần");
    default -> System.out.println("Không hợp lệ");
}

// Vòng lặp
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

int count = 0;
while (count < 5) {
    System.out.println(count++);
}

// for-each (duyệt mảng/collection)
int[] arr = {1, 2, 3, 4, 5};
for (int num : arr) {
    System.out.println(num);
}
```

> **📝 Giải thích chi tiết code:**
> * `switch (day) { case "MON", ... -> ... }`: Cú pháp Switch Expression thế hệ mới (áp dụng từ Java 14). Sử dụng toán tử mũi tên `->` giúp thực thi trực tiếp câu lệnh tương ứng mà không cần từ khóa `break` ở mỗi nhánh như cú pháp cũ, đồng thời hỗ trợ ghép nhiều điều kiện `case "MON", "TUE"`.
> * `for (int i = 0; i < 5; i++)`: Vòng lặp `for` truyền thống gồm 3 phần: khởi tạo biến chạy `int i = 0`, điều kiện dừng `i < 5`, và bước tăng `i++` sau mỗi lần lặp.
> * `while (count < 5)`: Vòng lặp `while` chỉ nhận vào biểu thức điều kiện. Khối code bên trong sẽ lặp đi lặp lại chừng nào điều kiện vẫn là `true`.
> * `for (int num : arr)`: Vòng lặp **for-each** (Enhanced for loop). Dùng để duyệt qua lần lượt từng phần tử của mảng hoặc Collection mà không cần sử dụng biến chỉ mục (index). Trong mỗi lần lặp, phần tử hiện tại sẽ được gán vào biến `num`.

## 4. Mảng (Array)

> **🔍 WHAT:** Mảng là cấu trúc dữ liệu lưu trữ nhiều phần tử cùng kiểu dữ liệu trong một biến, truy cập bằng chỉ số (index) bắt đầu từ 0.
>
> **💡 WHY:** Cần lưu trữ tập hợp dữ liệu cùng loại một cách có thứ tự và truy cập theo vị trí – ví dụ danh sách ID, mảng byte khi đọc file.
>
> **⚙️ HOW:** Khai báo với `kiểuDữLiệu[] tênMảng = new kiểuDữLiệu[kích_thước]` hoặc khởi tạo trực tiếp `{1, 2, 3}`. Kích thước cố định sau khi tạo – dùng `ArrayList` nếu cần mảng động.
>
> **📍 WHEN/WHERE:** Dùng khi làm việc với dữ liệu cố định kích thước, xử lý binary data (byte[]), hoặc các API trả về array. Trong hầu hết business logic nên dùng `List` thay thế.

```java
// Khai báo
int[] numbers = new int[5];       // mảng 5 phần tử, mặc định = 0
String[] names = {"Alice", "Bob", "Charlie"};

// Truy cập
System.out.println(names[0]);     // Alice
System.out.println(names.length); // 3

// Mảng 2 chiều
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
System.out.println(matrix[1][2]); // 6

// Sắp xếp mảng
import java.util.Arrays;
int[] arr = {5, 2, 8, 1, 9};
Arrays.sort(arr); // {1, 2, 5, 8, 9}
System.out.println(Arrays.toString(arr));
```

> **📝 Giải thích chi tiết code:**
> * `int[] numbers = new int[5]`: Khởi tạo một mảng số nguyên gồm 5 phần tử. Tất cả phần tử được cấp phát mặc định giá trị ban đầu là `0` (với mảng đối tượng sẽ là `null`).
> * `names[0]`: Truy cập phần tử đầu tiên của mảng. Chỉ mục của mảng luôn bắt đầu từ số `0` và kết thúc tại `length - 1`.
> * `int[][] matrix`: Khai báo mảng hai chiều (thực chất là một mảng chứa các mảng một chiều). `matrix[1][2]` sẽ truy cập vào hàng chỉ mục `1` (hàng thứ hai `{4, 5, 6}`) và cột chỉ mục `2` (phần tử thứ ba trong hàng đó), kết quả là `6`.
> * `Arrays.sort(arr)`: Sử dụng phương thức tĩnh trong class helper `Arrays` để sắp xếp mảng theo thứ tự tăng dần.
> * `Arrays.toString(arr)`: Chuyển đổi toàn bộ mảng thành một chuỗi String có định dạng dễ đọc như `[1, 2, 5, 8, 9]` để in ra màn hình (nếu chỉ dùng `arr.toString()` sẽ ra mã băm của đối tượng).

## 5. String

> **🔍 WHAT:** `String` là kiểu dữ liệu đặc biệt trong Java đại diện cho chuỗi ký tự Unicode, là immutable object (không thay đổi sau khi tạo).
>
> **💡 WHY:** String được dùng ở khắp nơi – tên, email, nội dung, JSON response, SQL query... Hiểu String API giúp xử lý dữ liệu text hiệu quả và tránh các lỗi phổ biến như so sánh sai.
>
> **⚙️ HOW:** String có kho phương thức phong phú (length, substring, contains, replace...). Vì immutable, nên dùng `StringBuilder` khi nối nhiều String trong vòng lặp để tránh tạo quá nhiều object.
>
> **📍 WHEN/WHERE:** Dùng để xử lý mọi dữ liệu text – validate input, format response, build query, xử lý file. Đặc biệt quan trọng trong Controller (nhận/trả String) và Service (xử lý business text).

```java
String s = "Hello Java";

// Các phương thức phổ biến
s.length();           // 10
s.toUpperCase();      // "HELLO JAVA"
s.toLowerCase();      // "hello java"
s.trim();             // xóa khoảng trắng đầu cuối
s.substring(0, 5);    // "Hello"
s.replace("Java", "World"); // "Hello World"
s.contains("Java");   // true
s.split(" ");         // ["Hello", "Java"]
s.charAt(0);          // 'H'
s.indexOf("Java");    // 6

// So sánh String – LUÔN dùng equals()
String a = "hello";
String b = "hello";
a.equals(b);          // true ✅
a == b;               // KHÔNG đảm bảo ❌
a.equalsIgnoreCase(b); // true (không phân biệt hoa thường)

// StringBuilder – hiệu quả hơn khi nối nhiều String
StringBuilder sb = new StringBuilder();
sb.append("Hello").append(", ").append("World!");
String result = sb.toString(); // "Hello, World!"

// Text Blocks (Java 15+)
String json = """
        {
            "name": "Alice",
            "age": 25
        }
        """;
```

> **📝 Giải thích chi tiết code:**
> * `s.substring(0, 5)`: Cắt chuỗi từ chỉ mục bắt đầu `0` (inclusive - bao gồm) đến chỉ mục kết thúc `5` (exclusive - loại trừ). Kết quả là chuỗi gồm 5 ký tự đầu: `"Hello"`.
> * `a.equals(b)` vs `a == b`: 
>   * `equals()`: So sánh nội dung thực tế bên trong hai chuỗi ký tự. Đây là cách chuẩn để so sánh String trong Java.
>   * `==`: So sánh địa chỉ vùng nhớ (tham chiếu) của hai đối tượng. Dù hai chuỗi có cùng nội dung nhưng nếu được khởi tạo khác vùng nhớ (ví dụ dùng `new String("hello")`), `==` sẽ trả về `false`.
> * `StringBuilder`: Một lớp cho phép xây dựng và sửa đổi chuỗi động (mutable). Do lớp `String` là bất biến (immutable) nên mỗi khi cộng chuỗi `+` Java sẽ tạo ra một đối tượng mới trong bộ nhớ, gây hao tổn tài nguyên. `StringBuilder` giải quyết vấn đề này bằng cách sửa đổi trực tiếp trên một mảng ký tự nội bộ.
> * `""" ... """`: **Text Blocks** (áp dụng từ Java 15). Cho phép viết chuỗi ký tự nhiều dòng mà không cần dùng ký tự xuống dòng `\n` hay dấu cộng chuỗi, rất hữu ích khi viết mã SQL, JSON hoặc HTML trực tiếp trong Java.

## 6. Phương thức (Method)

> **🔍 WHAT:** Phương thức (method) là khối code có tên, thực hiện một tác vụ cụ thể, có thể nhận tham số đầu vào và trả về kết quả.
>
> **💡 WHY:** Method giúp tái sử dụng code, tổ chức logic theo từng nhiệm vụ rõ ràng (SRP – Single Responsibility), giảm code lặp và dễ test hơn.
>
> **⚙️ HOW:** Khai báo với `[modifier] [kiểuTrảVề] tênMethod([thamSố])`. Method `void` không trả giá trị. Overloading cho phép nhiều method cùng tên nhưng khác signature.
>
> **📍 WHEN/WHERE:** Dùng để bọc mọi logic tái sử dụng – validate, transform data, tính toán. Trong Spring, mỗi endpoint controller gọi các method service, service gọi repository method.

```java
// Định nghĩa và gọi
public static int add(int a, int b) {
    return a + b;
}
int result = add(3, 5); // 8

// Overloading
public static double add(double a, double b) {
    return a + b;
}

// Varargs
public static int sum(int... numbers) {
    int total = 0;
    for (int n : numbers) total += n;
    return total;
}
sum(1, 2, 3, 4, 5); // 15

// Đệ quy
public static int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```

> **📝 Giải thích chi tiết code:**
> * `public static int add(int a, int b)`: Phương thức tĩnh nhận vào hai biến kiểu số nguyên `a`, `b` và trả về kết quả cộng cũng là kiểu số nguyên (`int`).
> * `Overloading` (Quá tải phương thức): Hai phương thức `add` có cùng tên nhưng khác nhau về kiểu dữ liệu tham số truyền vào (`int` vs `double`). Java sẽ tự nhận diện kiểu dữ liệu truyền vào khi chạy để gọi đúng phương thức tương ứng.
> * `int... numbers`: Cơ chế **Varargs** (Variable Arguments - Số lượng đối số biến đổi). Thực chất, Java coi `numbers` là một mảng `int[]`. Nó cho phép bạn truyền vào bao nhiêu tham số kiểu `int` tùy ý (thậm chí là không truyền gì), giúp cú pháp gọi hàm trở nên linh hoạt hơn.
> * `factorial(int n)`: Một phương thức đệ quy (tự gọi lại chính nó). Hàm tính giai thừa có điểm dừng điều kiện là `n <= 1` để tránh vòng lặp đệ quy vô hạn dẫn tới lỗi `StackOverflowError`.

## 7. Collections Framework

> **🔍 WHAT:** Collections Framework là bộ thư viện Java chuẩn cung cấp các cấu trúc dữ liệu quan trọng: List (danh sách), Set (tập hợp không trùng), Map (cặp key-value), Queue (hàng đợi).
>
> **💡 WHY:** Thay vì tự cài đặt cấu trúc dữ liệu phức tạp, Collections Framework cung cấp sẵn các implementation đã được tối ưu hóa và test kỹ lưỡng – tiết kiệm thời gian và tránh lỗi.
>
> **⚙️ HOW:** Dùng interface (`List`, `Set`, `Map`) để khai báo kiểu, dùng implementation cụ thể (`ArrayList`, `HashSet`, `HashMap`) để khởi tạo. Từ Java 9+ có thể dùng `List.of()`, `Map.of()` cho immutable collections.
>
> **📍 WHEN/WHERE:** Dùng khắp nơi trong ứng dụng – trả về danh sách từ repository, nhóm dữ liệu bằng Map, loại bỏ trùng lặp bằng Set, xử lý hàng đợi tác vụ.

```java
import java.util.*;

// List – có thứ tự, cho phép trùng
List<String> list = new ArrayList<>();
list.add("Apple");
list.add("Banana");
list.add("Cherry");
list.get(0);         // "Apple"
list.size();         // 3
list.remove("Banana");
list.contains("Apple"); // true

// Set – không trùng, không đảm bảo thứ tự
Set<String> set = new HashSet<>();
set.add("A");
set.add("B");
set.add("A"); // bị bỏ qua
set.size();   // 2

// Map – key-value pairs
Map<String, Integer> map = new HashMap<>();
map.put("Alice", 30);
map.put("Bob", 25);
map.get("Alice");          // 30
map.containsKey("Bob");    // true
map.getOrDefault("Charlie", 0); // 0

// Duyệt Map
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + " = " + entry.getValue());
}

// Queue (FIFO) và Stack (LIFO)
Queue<String> queue = new LinkedList<>();
queue.offer("A"); queue.offer("B");
queue.poll();  // "A"

Deque<String> stack = new ArrayDeque<>();
stack.push("A"); stack.push("B");
stack.pop();   // "B"
```

> **📝 Giải thích chi tiết code:**
> * `List<String> list = new ArrayList<>()`: Sử dụng Interface `List` làm kiểu khai báo và class `ArrayList` làm đối tượng thực tế (Tính đa hình). `ArrayList` hoạt động dựa trên một mảng động tự co giãn kích thước.
> * `Set<String> set = new HashSet<>()`: `HashSet` sử dụng cơ chế bảng băm (Hash Table) để lưu trữ phần tử. Nó không cho phép lưu hai phần tử trùng lặp (trùng giá trị qua `equals()` và `hashCode()`) và không cam kết duy trì thứ tự chèn.
> * `Map<String, Integer> map = new HashMap<>()`: Lưu trữ dữ liệu dạng cặp Khóa - Giá trị (`Key-Value`). Các khóa (Key) là duy nhất. Phương thức `getOrDefault("Charlie", 0)` sẽ lấy giá trị của key `"Charlie"`, nếu key đó chưa tồn tại trong map thì trả về giá trị mặc định là `0` thay vì trả về `null`.
> * `map.entrySet()`: Trả về một Set chứa toàn bộ các đối tượng entry (cặp Key-Value) để ta có thể duyệt qua Map bằng vòng lặp for-each.
> * `queue.poll()`: Lấy ra và xóa phần tử đầu tiên được thêm vào hàng đợi (Cơ chế First In First Out - FIFO - Vào trước ra trước).
> * `stack.pop()`: Lấy ra và xóa phần tử trên cùng của ngăn xếp (Cơ chế Last In First Out - LIFO - Vào sau ra trước). `Deque` (Double Ended Queue) được khuyến nghị dùng thay thế cho class `Stack` cũ vốn đã bị coi là lỗi thời (legacy).

## 8. Xử lý ngoại lệ (Exception Handling)

> **🔍 WHAT:** Exception (ngoại lệ) là sự kiện bất thường xảy ra khi chạy chương trình. Exception Handling là cơ chế phát hiện, bắt và xử lý các lỗi đó một cách có kiểm soát.
>
> **💡 WHY:** Không xử lý exception thì ứng dụng sẽ crash khi gặp lỗi (chia cho 0, file không tồn tại, DB timeout...). Xử lý đúng cách giúp ứng dụng resilient và trả thông báo lỗi có ý nghĩa cho client.
>
> **⚙️ HOW:** `try` bọc code có thể lỗi, `catch` bắt loại exception cụ thể, `finally` luôn chạy (dùng để đóng resource). `throw` ném exception mới, `throws` khai báo method có thể ném exception. `try-with-resources` tự đóng resource sau khi dùng.
>
> **📍 WHEN/WHERE:** Trong Service layer khi gọi DB/external API; Controller layer khi parse input; dùng `@RestControllerAdvice` để xử lý tập trung tất cả exception trong Spring Boot.

```java
// try-catch-finally
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Lỗi: " + e.getMessage());
} catch (Exception e) {
    System.out.println("Lỗi tổng quát: " + e.getMessage());
} finally {
    System.out.println("Luôn chạy – dùng để dọn dẹp");
}

// Ném ngoại lệ
public static void checkAge(int age) {
    if (age < 0) {
        throw new IllegalArgumentException("Tuổi không hợp lệ: " + age);
    }
}

// Custom Exception
public class ResourceNotFoundException extends RuntimeException {
    public ResourceNotFoundException(String message) {
        super(message);
    }
}

// try-with-resources (tự đóng resource)
try (BufferedReader br = new BufferedReader(new FileReader("file.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException e) {
    e.printStackTrace();
}
```

> **📝 Giải thích chi tiết code:**
> * `try { ... } catch (ArithmeticException e) { ... }`: Khối code có khả năng xảy ra lỗi chia cho 0 được bao bọc trong `try`. Khi xảy ra lỗi `ArithmeticException`, luồng thực thi lập tức nhảy sang khối `catch` tương ứng để xử lý và chương trình vẫn tiếp tục chạy bình thường mà không bị crash giữa chừng.
> * `finally`: Khối lệnh luôn luôn được thực thi dù cho có xảy ra exception hay không. Nó thường được dùng để giải phóng tài nguyên hệ thống (đóng file, ngắt kết nối database).
> * `throw new IllegalArgumentException(...)`: Chủ động ném ra một đối tượng Exception để báo hiệu cho phương thức gọi bên ngoài biết rằng dữ liệu truyền vào không hợp lệ.
> * `ResourceNotFoundException extends RuntimeException`: Khai báo một ngoại lệ tự định nghĩa. Việc kế thừa `RuntimeException` biến ngoại lệ này thành dạng **Unchecked Exception** (ngoại lệ khi chạy) – nghĩa là các phương thức gọi không bắt buộc phải khai báo `throws` hay dùng `try-catch` một cách cưỡng ép trong code.
> * `try (BufferedReader br = new BufferedReader(...))`: Cơ chế **try-with-resources** (áp dụng từ Java 7). Bất kỳ đối tượng nào khởi tạo trong ngoặc đơn của `try` mà implement interface `AutoCloseable` (như các stream đọc/ghi file, kết nối socket, kết nối database) sẽ **tự động được đóng lại** khi khối `try` kết thúc, ngay cả khi có Exception xảy ra. Điều này giúp ngăn ngừa triệt để lỗi rò rỉ bộ nhớ (Memory Leak) mà không cần viết khối `finally` cồng kềnh.
