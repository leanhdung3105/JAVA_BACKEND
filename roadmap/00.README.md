## 🎯 Mục tiêu sau khi hoàn thành

- ✅ Thành thạo ngôn ngữ Java và lập trình hướng đối tượng
- ✅ Xây dựng được RESTful API hoàn chỉnh với Spring Boot
- ✅ Kết nối và thao tác với cơ sở dữ liệu qua JPA/Hibernate
- ✅ Bảo mật API với Spring Security và JWT
- ✅ Viết unit test và integration test
- ✅ Triển khai ứng dụng lên server bằng Docker
- ✅ Hiểu kiến trúc Microservices cơ bản
- ✅ Sẵn sàng đi làm vị trí Java Backend Developer

---

## 📦 Tech Stack chính

```
Java 17+ → Spring Boot 3.x → Spring Data JPA → PostgreSQL/MySQL
Spring Security → JWT → Redis → RabbitMQ/Kafka
Docker → GitHub Actions → AWS/GCP
```
